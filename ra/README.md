# PonteTrucha RA — Komatsu HD785-7

Página de demostración para visualizar el camión en 3D y probar RA con `<model-viewer>`.

## Archivos de modelo requeridos

Colocar dentro de `ra/assets/`:

- `komatsu-hd785-7.glb` — modelo web optimizado.
- `komatsu-hd785-7.usdz` — modelo para Apple Quick Look.

Los dos archivos están incluidos en el paquete de demostración entregado en esta conversación. No se incluyen todavía en este commit porque el conector de GitHub disponible permite crear archivos de texto, pero no transferir directamente estos binarios.

## Pruebas

La RA requiere HTTPS y un dispositivo/navegador compatible. Android puede usar Scene Viewer o WebXR; iOS puede usar Quick Look. El visor 3D debe seguir funcionando si RA no está disponible.
